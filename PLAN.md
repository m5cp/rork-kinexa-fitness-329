# Elevated cards everywhere, rebrand USDA search, add References section to Profile

## What will change

### 1. Elevated card styling across the whole app

- Apply the same raised, soft-shadow look seen on the Progress page to every card/bubble in the app — Home, Nutrition, Workouts, Plan, Profile, and all sub-screens.
- Create one shared elevated card style so every page has a consistent premium feel.
- Cards sit slightly above the background with a subtle shadow and rounded corners, automatically adjusting for light, dark, and system mode so shadows stay tasteful in both themes.
- Keep all existing colors, layouts, and content — only the card surface styling is upgraded.

### 2. Rebrand the "USDA Search" option

- The existing food database search stays fully functional.
- Rename the card in the Log Meal screen from "USDA Search / Verified database" to a cleaner, brand-neutral name: **"Food Search" / "Search foods & brands"**.
- Remove every user-facing mention of "USDA" from the nutrition flow (scan fallback list, database result badge, loading text, empty states, etc.).
- The search continues to pull from the same verified food database behind the scenes.

### 3. Add a "References" section on the Profile page

- New section on the Profile screen titled **REFERENCES**, styled like the existing Legal and Support sections.
- Contains a single row: **"Food Data Source"** that opens a simple info screen crediting the USDA FoodData Central database as the source of verified nutrition information.
- This keeps proper attribution in one respectful, discoverable place without cluttering the logging flow.

## Visual result

- Every screen feels more dimensional and polished — cards "float" consistently.
- The meal logging screen looks cleaner and less technical; users see friendly names instead of a government acronym.
- Attribution lives quietly in the Profile page where curious users can find it.
